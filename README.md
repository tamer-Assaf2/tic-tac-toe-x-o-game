# 🎮 X-O Game (Tic Tac Toe)

مرحبًا بك في لعبة **X-O** الكلاسيكية بتصميم عصري وبرمجة بسيطة باستخدام **HTML**, **CSS**, و **JavaScript**!  
اللعبة مناسبة لشخصين على نفس الجهاز، مع نظام إعلان فائز ورسالة تعادل مع زر إعادة تشغيل سريع.

## ⚙️ التقنيات المستخدمة

- 🌐 **HTML5** — بناء هيكل الصفحة.
- 🎨 **CSS3** — تنسيقات احترافية واستجابة مع حجم الشاشة.
- 🧠 **JavaScript (Vanilla)** — منطق اللعبة، التفاعل مع الأزرار والتحقق من الفائز.

---

## 🎮 طريقة اللعب

1. يبدأ اللاعب الأول باستخدام الرمز `O`.
2. ثم يتناوب اللاعبان في الضغط على الخانات.
3. أول من يشكل ثلاث رموز متتالية أفقيًا، عموديًا أو قطريًا يفوز.
4. في حال امتلاء جميع الخانات بدون فائز — تُعلَن اللعبة تعادل.
5. يمكن إعادة تشغيل اللعبة باستخدام زر **Reset Game** أو **New Game**.
